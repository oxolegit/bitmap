# bitmap

https://bitmap.mslv.space

Генератор двухцветных bitmap-изображений. Каждая генерация уникальна: картинку определяет короткий seed, и по одной ссылке всегда открывается одно и то же изображение.

![bitmap](og.png)

## Что умеет

- **Генеративные основы.** Странные аттракторы (Клиффорд, де Йонг, Свенссон, Bedhead), реакция-диффузия Грея–Скотта, линии течений, шум с domain warp (дым, мрамор, изолинии, террасы), интерференция и муар, тепловое поле, хребты, планеты с кольцами, спирали, Вороной, суперформула.
- **Сборка картинки.** Иногда два слоя (умножение, маска, разность, осветление), зеркальная и калейдоскопическая симметрия, композиция во весь кадр, по горизонту или с мягким затуханием, изолинии и постеризация.
- **Дизеринг.** Atkinson, Floyd–Steinberg, Jarvis–Judice–Ninke, Stucki, Sierra Lite, Bayer 2/4/8, blue noise (void-and-cluster), IGN, полутоновый растр точками и линиями, порог. Можно оставить «Авто» или выбрать вручную.
- **Фильтр качества.** Слишком пустые, сплошные и бесструктурные варианты отбрасываются ещё до показа.
- **Формат.** 1:1, 4:5, 3:4, 2:3, 9:16, 16:9, 3:2, 21:9, A4 или свой размер до 8192 px по стороне; размер пикселя от 1 до 16.
- **Палитры.** Восемь двухцветных пар и свои цвета. Палитра меняется мгновенно, без перерисовки.
- **Экспорт.** PNG ровно в выбранном разрешении и SVG, в котором чернила собраны в прямоугольники.
- **Ссылки и история.** Все настройки хранятся в адресе страницы. Последние 12 картинок доступны в ленте истории.
- **Интерфейс** на русском и английском.

Горячие клавиши: пробел — новая картинка, ← → — история, P — PNG, S — SVG.

## Запуск

Сборка не нужна: это статический сайт на ES-модулях, тяжёлый расчёт идёт в Web Worker.

```sh
npx serve .
```

Проверки генератора (детерминизм, разнообразие, фильтр качества, геометрия SVG):

```sh
node tests/run.js
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `gen/rng.js` | seed → генератор случайных чисел (cyrb128 + sfc32) |
| `gen/noise.js` | шум Перлина, fBm, ridged, domain warp |
| `gen/fields.js` | генеративные основы, координаты нормированы по высоте кадра |
| `gen/recipe.js` | seed → рецепт: слои, симметрия, композиция, тон, дизеринг |
| `gen/dither.js` | алгоритмы дизеринга |
| `gen/quality.js` | фильтр скучных результатов |
| `render.worker.js` | рендер в фоновом потоке |
| `export.js` | PNG и SVG |
| `app.js`, `i18n.js` | интерфейс и переводы |
